# 2facode

Локальный TOTP (2FA) генератор, работающий полностью в браузере.

## Возможности

- Base32-секреты и `otpauth://` ссылки
- TOTP с SHA-1, SHA-256 и SHA-512
- 6, 7 или 8 цифр
- Индикатор времени до обновления кода
- Копирование одноразового кода
- Секрет не отправляется на сервер и не сохраняется автоматически

## Запуск

Откройте `index.html` в современном браузере или разместите репозиторий через GitHub Pages.

> Не добавляйте реальные 2FA-секреты в репозиторий.
