Как хранятся данные

Описание актуально на 20 августа 2026 года

1. Где находятся данные

Добавленные записи находятся в localStorage браузера для домена code.0ce.ru. Приложение читает их только на вашем устройстве.

2. Как создаётся код

TOTP-код вычисляется в браузере из сохранённого секретного ключа и текущего времени по параметрам записи. Для вычисления используется Web Crypto API браузера.

3. Что хранится

  • название записи;
  • секрет TOTP и параметры алгоритма;
  • логин и пароль, если они введены;
  • заметка длиной до 20 символов.

4. Что не отправляется приложением

JavaScript Сервиса не отправляет содержимое записей в серверную базу. В текущей версии для работы Authenticator не требуется аккаунт или синхронизация.

5. Когда данные могут исчезнуть

Данные могут быть потеряны при очистке данных сайта, удалении профиля браузера, переустановке браузера/ОС, поломке устройства или использовании приватного режима. Храните резервные коды сервисов отдельно.

6. Как удалить всё

Удалите записи в интерфейсе либо очистите данные сайта code.0ce.ru в настройках браузера. После этого локальная копия недоступна Сервису.
